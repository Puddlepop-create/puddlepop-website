PUDDLEPOP WEBSITE
=================

Open index.html to preview the website locally.

Upload every file and folder in this package to the public web root for puddlepop.app.
Keep the assets folder structure unchanged.

Included pages:
- index.html      Main website
- support.html    Parent support page
- privacy.html    Temporary pre-release placeholder
- terms.html      Temporary pre-release placeholder
- 404.html        Branded page-not-found screen

Important before Google Play production release:
1. Replace the privacy placeholder with a complete policy matching the final app.
2. Review and complete the terms when pricing and purchases are final.
3. Replace the Coming Soon labels with the official Google Play link and badge.
4. Test all pages on the live domain and verify puddlepop.app in Google Search Console.
